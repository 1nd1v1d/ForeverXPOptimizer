# Changelog

## 0.2.0 — 2026-11-05

- Automatic interface language selection from the WoW client's text locale.
- Complete translation tables for English, German, French, Spanish, Italian, Portuguese, Russian, Korean, Simplified Chinese and Traditional Chinese.
- Shared translations for enGB, esMX and ptPT; English fallback for unknown locales and missing translations.
- Localized source descriptions, buff states, warnings, buttons, quest previews, level history, help and diagnostics.
- Locale-aware integer grouping and decimal display; UTF-8-safe XP-tooltip matching.
- XP food and undead-target detection across supported languages.
- English command aliases: reset, sound, source and status. Existing German commands remain valid.
- Translation completeness checks and full client/UI tests across all supported locale variants and fallback.
- Updated README, packaged instructions and English/German CurseForge descriptions.
- Versioned ZIP packaging includes every locale file and derives its version from the TOC.

## 0.1.0 — 2026-11-05

- Initial XP booster overview and buff reminders.
- Active XP/hour, separate AFK tracking, playtime and level history.
- Completed-quest XP overlay and projected level progress.
- Project logo and standalone AddOn package.
